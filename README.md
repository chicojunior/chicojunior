
# Hey, I'm Francisco, but Chico works too 👋

### Frontend Engineer · Angular · TypeScript · Frontend Architecture

> I build frontends that survive redesigns, framework upgrades,
> legacy code, and those suspiciously simple "quick change" requests.

Originally from 🇧🇷 **Fortaleza, Brazil**, now based in 🇵🇹 **Porto, Portugal**.

I've been building web applications professionally since **2015**, mostly working on enterprise products with international teams.

My specialty is **Angular + TypeScript**, particularly modernizing existing applications, improving frontend architecture, and building interfaces that are easier to evolve and maintain.

I like code that's easy to understand, systems that age well, and releases that are boring — in the best possible way.

---

## 🧑‍💻 What I work on

- **Frontend engineering:** Building and evolving Angular applications for real-world business workflows.
- **Modernization:** Upgrading frameworks and refactoring legacy code without putting feature delivery on hold.
- **UI architecture:** Creating reusable components and shared libraries across applications.
- **Quality:** Testing, maintainability, responsive UX, and reducing technical debt.
- **Collaboration:** Working with product, design, backend, and QA teams to turn requirements into reliable software.

I care about the difference between **"it works"** and **"we can still understand this code two years from now."**
